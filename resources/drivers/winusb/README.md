# WinUSB driver packages (Zadig/libwdi-generated)

The two packages in this directory bind the Capsula boards to WinUSB on
Windows, which is the transport capsula-jb (nusb) requires. They are
embedded into the binary at build time (`crates/win-drv/src/lib.rs`)
and installed automatically on first use: no manual Zadig step.

| package     | hardware ID            | covers                                    |
|-------------|------------------------|-------------------------------------------|
| capsula-330d| `USB\VID_2207&PID_330D` | u-boot loader (rockusb)                   |
| capsula-330e| `USB\VID_2207&PID_330E` | MaskROM and the RAM-loaded usbplug (both) |

Each directory holds:

- `*.inf` — the libwdi WinUSB extension INF (UTF-16, matched by hardware
  ID; MaskROM/usbplug share one PID and differ only by iProduct, which
  does not take part in driver matching);
- `*.cat` — the catalog **signed by Zadig over this exact INF**: the INF
  is a signed member, so the files must never be renamed or edited;
- `*.cer` — the self-signed signer certificate, extracted from the
  catalog. The installer adds it to the machine ROOT and
  TrustedPublisher stores — the same trust model Zadig itself uses.

## Provenance and licensing

Generated by Zadig 2.9 (Pete Batard, https://github.com/pbatard/libwdi,
GNU LGPL) by binding the respective device to WinUSB. The INF header
carries the libwdi copyright; redistribution follows the same terms as
bundling `zadig-2.9.exe` itself (see the README license section).

## Regenerating

Only needed when a new board PID must be supported:

1. Put the board into the mode that enumerates with the new PID.
2. Run Zadig → Options → List All Devices → select the `2207:xxxx`
   device → WinUSB → Replace Driver.
3. Export the generated package from the driver store:
   `pnputil /enum-drivers` (find the `oemNN.inf` with Original Name =
   the device string), then `pnputil /export-driver oemNN.inf <dir>`.
4. Extract the signer cert: in PowerShell,
   `[IO.File]::WriteAllBytes("pkg.cer", (Get-AuthenticodeSignature <dir>\*.cat).SignerCertificate.Export("Cert"))`.
5. Add the files under `resources/drivers/winusb/capsula-xxxx/` and a
   `Package` entry in `crates/win-drv/src/lib.rs`.

A package for the post-jailbreak adb gadget (`2207:0006`) can be
generated the same way once a live gadget is available; USB adb also
works through any installed Google/Android WinUSB driver, and adb over
Wi-Fi needs no driver at all.
