USB-драйверы на Windows
=======================

Обычно ничего делать не нужно: capsula-jb сам ставит WinUSB и держит
плату на нём всю сессию. Этот файл — на случай проблем и для
переключения обратно на вендорский драйвер (RKDevTool и другие
официальные утилиты Rockchip).

Как работает автоматика
-----------------------
Пока capsula-jb работает с платой, та меняет USB-личины (лоадер 330d,
MaskROM/usbplug 330e) — и Windows каждый раз подбирает драйвер заново,
причём вендорский Rockusb выигрывает у WinUSB. Поэтому capsula-jb:

- запускается целиком с правами администратора (UAC-запрос — один раз,
  в самом начале);
- несёт WinUSB-пакеты прямо в бинарнике и ставит их тем же API, что и
  Zadig, вместе с сертификатами;
- следит за шиной и перевязывает плату на WinUSB при каждой смене
  личности.

Лог драйверной сессии: %TEMP%\capsula-jb-winusb-<pid>\session.log.
Из обычного (непривилегированного) терминала Windows поднимет
инструмент в отдельное окно с паузой в конце — вывод не пропадёт.

Ручная привязка WinUSB (запасной путь)
--------------------------------------
Нужно только если автоматика не справилась (например, UAC отклонили):

1. Введите колонку в режим лоадера (см. QUICKSTART.txt).
2. Запустите zadig-2.9.exe из этой папки, Options -> List All Devices.
3. Выберите устройство с USB ID 2207:330D (в списке оно называется
   «USB download gadget» — ориентируйтесь на ID, а не на имя), сверху
   выберите WinUSB и нажмите Replace Driver. Повторите для 2207:330E.
4. Проверка:

   powershell -NoProfile -Command "Get-PnpDevice | Where-Object { $_.InstanceId -match 'VID_2207&PID_330D' } | Get-PnpDeviceProperty -KeyName DEVPKEY_Device_Service | Format-List KeyName,Data"

   Data: WinUSB — готово.

Вернуть вендорский драйвер (для RKDevTool)
------------------------------------------
Привязка Zadig/capsula-jb главнее вендорского INF — простая переустановка
DriverAssistant не вернёт плату. Порядок такой:

1. Диспетчер устройств -> найти плату -> «Удалить устройство» с
   флажком «Удалить драйвер для этого устройства».
2. Установить вендорский пакет: распаковать RockchipUSBDriver.zip,
   запустить DriverInstall.exe из DriverAssitant_v5.14, дождаться
   «Install OK». Затем «Обновить конфигурацию оборудования» или
   переподключить плату.
3. Проверить той же командой: Data: Rockusb.

Пока capsula-jb запущен, он перевязывает плату обратно на WinUSB —
закройте его перед работой с RKDevTool.

После джейлбрейка adb по USB (гаджет 2207:0006) заработает с любым
Google/Android SDK-драйвером, а adb по Wi-Fi (adb connect <ip>:5555)
не требует драйвера вовсе.
